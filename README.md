# RecoverLand

RecoverLand is a QGIS plugin for local GIS data audit and recovery. It automatically captures every modification (attribute, geometry, deletion) in a local SQLite journal, then lets you search, compare and restore previous states of features.

## Documentation

Technical documentation is in [`docs/`](docs/index.html). QGIS 3.40 through 4.99 (Qt5 and Qt6). No extra dependency: the journal is SQLite, which ships with QGIS.
