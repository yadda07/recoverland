about=RecoverLand records every committed vector layer edit (inserts, attribute updates, geometry changes, deletions) into a local SQLite journal with zero external dependencies and no server setup. Key capabilities: (1) Search and Compare: filter history by layer, action, user or date range and inspect attribute and geometry diffs on the map canvas; (2) Review Snapshot: reconstruct and explore a non-destructive read-only memory snapshot of any layer as it stood at a chosen timestamp t; (3) Selective Restore and Temporal Rewind: roll back individual features or rewind a layer to a cutoff timestamp with preflight validation, post-commit provider verification (CommitGuard), and deterministic FID tracking across Shapefile repacks. Supports GeoPackage, Shapefile, PostgreSQL/PostGIS, SpatiaLite, MSSQL, Oracle, GeoJSON, FlatGeobuf and CSV across QGIS 3.40 LTR and QGIS 4.x (Qt5 and Qt6); temporary memory layers are ignored silently and tracked automatically once saved permanently. Documentation: https://yadda07.github.io/recoverland/ | Contribution : Youcef ADDA | GEODECI.     Version 7.2.0
    - Silent handling of temporary and scratch layers (memory, virtual, broken, and review overlays): no more error banners, hidden from the tracked-layer selector, and tracked automatically once saved permanently.
    - Stronger local SQLite durability: atomic schema migrations and purge boundaries, safe recovery on disk-full writes, lock-takeover protection with automatic write halt, UNC path support, and Windows file-lock resilience.
    - Improved capture and restoration on QGIS 3.40 LTR and 4.x (Qt5/Qt6): PyQt6 null-value fix, in-session Field Calculator schema sync, dirty transaction-group guard, filtered-layer readback, Z/M and curved geometry handling, and exclusion of virtual, joined, and read-only fields.
    - Smoother UI and full Qt6 compliance: interruptible background queries, sort-aware table context menu, clean task cancellation on project switch, and zero issues on the official QGIS Qt6 checker.
    Version 7.1.5
    - Fixed search results failing when mixing geometry updates with INSERT or DELETE events.
    - Fixed the Rewind time slider showing the oldest bound in UTC instead of local time.
    Version 7.1.4

    Version 7.1.3
