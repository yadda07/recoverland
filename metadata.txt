description=Local GIS data audit and recovery: automatic capture, search and restoration of modifications
about=RecoverLand records every committed vector layer edit (inserts, attribute updates, geometry changes, deletions) into a local SQLite journal with zero external dependencies and no server setup. Key capabilities: (1) Search and Compare: filter history by layer, action, user or date range and inspect attribute and geometry diffs on the map canvas; (2) Review Snapshot: reconstruct and explore a non-destructive read-only memory snapshot of any layer as it stood at a chosen timestamp t; (3) Selective Restore and Temporal Rewind: roll back individual features or rewind a layer to a cutoff timestamp with preflight validation, post-commit provider verification (CommitGuard), and deterministic FID tracking across Shapefile repacks. Supports GeoPackage, Shapefile, PostgreSQL/PostGIS, SpatiaLite and Memory layers across QGIS 3.40 LTR and QGIS 4.x (Qt5 and Qt6). Documentation: https://yadda07.github.io/recoverland/ | Contribution : Youcef ADDA | GEODECI. REWIND & RESTORE CONTINUITY: multi-repack Shapefile lifetimes are tracked across successive deletions via deterministic end-of-session FID shift propagation (shifted_state_at in core/rewind_dedup.py); relocated target FIDs verified at the head of an entity chain are carried across all subsequent UPDATE steps in the same buffer session (_RELOCATED_SLOT in core/restore_executor.py), supporting 100+ chained edits and multi-hop temporal round-trips without losing target proof; _CommittedIndex indexes live bounding boxes and attribute holders in memory with an editBuffer() overlay in core/restore_service.py. COMMIT GUARD PERFORMANCE & FIDELITY: two-tier signature comparison (_fast_signature on raw WKB bytes with canonical _vertex_key fallback only on unmatched residuals) cuts post-commit verification time by 48x on dense layers; _canon_value normalizes ISO datetime strings against QDateTime instants so applyOnUpdate timestamp fields never trigger false mismatches; _fresh_layer synchronizes provider encoding (_sync_layer_encoding) and _affected_area uses _finite_box with minimum span padding so Point geometries are never missed. UI & ANIMATION: ThemedLogoWidget replaces particle/ribbon and CPU QGraphicsDropShadowEffect blur with a single glyph-masked specular wave on a cached HiDPI QPixmap (CompositionMode_SourceAtop, 30 FPS cap); progress_bar updates in O(1) without concurrent QVariantAnimation timers; resolve_theme reads QApplication.palette() directly to prevent recursive QSS palette drift. 7.0.0 Journal schema v7: durable capture outbox, crash reconciliation, post-commit verification, and modern vector UI. DURABILITY: before a commit reaches the provider, EditSessionTracker writes a durable pre-commit snapshot into a per-journal JSONL outbox (capture_outbox), fsyncs the post-commit diff, and indexes idempotently into SQLite via event_uid and commit_id. At startup, crash_reconcile inspects any interrupted commit against the live provider state and records exact recovery events without duplicating or guessing. RESTORE & REWIND: CommitGuard verifies post-commit provider state on every restore/rewind/undo and compensates automatically on partial provider failure; composite primary keys (pk_fields) and multi-hop restore chains are resolved deterministically; purge intervals and unvouched Save As history floors are tracked in journal_coverage and journal_coverage_gap so a rewind never silently crosses a purged or unverified interval; explicit NULL geometry marker (event_schema_version 7) distinguishes cleared geometries from unchanged ones. REVIEW: SnapshotRebuildWorker streams bounded SQL batches off the GUI thread, supports composite keys and unstable-FID repacked layers, and verifies CRS compatibility before rendering. UI & I18N: modern vector SVG icon catalogue rendered directly via QPainter at native HiDPI without raster artifacts; unified dark/light theme tokens; complete 568-entry FR/EN translation catalogue verified at build time. 6.0.0 Journal schema v6 and a rewind that stops lying. SCHEMA: the datasource fingerprint was wrong in three ways -- DB providers captured the SCHEMA where they meant the table (every table of a schema shared one identity, so an INSERT in one and a DELETE in another cancelled out and neither was restored), a display filter appended |subset= and split one file's history in two, and spatialite/delimitedtext ran abspath on something that is not a path. Fixed through QgsDataSourceUri, and the past is reconciled WITHOUT REWRITING ANYTHING: migration v6 records old->canonical rows in datasource_alias (a table present since v4 with no caller) and the read paths expand a fingerprint into its historical forms. No audit_event row is touched; deleting the alias rows restores the previous state exactly. Ambiguity is never guessed: when an old DB fingerprint would have to split into several, no alias is written and the source is NAMED to the user before a rewind. Capture never depends on a journal row -- the pre-v6 normaliser is kept so a tracked-layer selection saved by any version keeps designating the same layers. A read-only journal still opens. DATA LOSS FIXED: the rewind no longer writes on a target it cannot prove, on either engine (a repacked shapefile made it overwrite an unrelated feature and report success); a datetime no longer loses the local offset on every write (it drifted cumulatively); a binary field is no longer restored as the ASCII of its own base64 label; gid/username stop being classed as audit noise, so a re-inserted feature keeps its primary key; the literal text 'NULL' is no longer erased at capture; an entity deleted then re-created comes back with ALL its fields, and a chain of more than ten edits reverts every field it touched, not just the oldest. SILENT LOSS FIXED: WriteQueue no longer acknowledges events with no live writer and survives a non-SQLite exception; pending events are actually re-integrated (they never were, not once); a journal on a path holding '#' no longer opens EMPTY on read while capture writes fine; the excess purge no longer cuts a commit in half; capture reads PROVIDER fields, so a joined layer stops producing phantom attribute changes; the capture lock is released when a restore dies. TRUTH: a rewind that had to abandon fields now says so and NAMES them instead of reporting a complete restore; undoing an INSERT whose feature is already gone is a skip, not a failure. REVIEW: the lens ran on the local wall clock while the journal is UTC -- both modes now denote the same instant. PACKAGING: supportsQt6, without which Qt6 builds of QGIS 3.x refused to load the plugin at all. VALIDATION: 60+ runtime scenarios versioned and run headless by CI, on a Qt6 image the matrix never covered.
